# 🏆 Leaderboard — measured comparative rankings

## 📁 Directory structure

```text
leaderboard/
├── results.csv   # MEASURED. Generated by evaluation/analyze.py.
└── README.md
```

`results.csv` is produced by executing real scanners over the admissible corpus. It
is the only leaderboard in this repository.

`evaluation/score.py` also writes a leaderboard, from hardcoded per-tool rates with
the reference implementation pinned to a perfect score. It measures nothing. Its
output previously lived here and has been deleted; the stage now writes
`results.synthetic.csv` and refuses to run without `IACSECBENCH_ALLOW_SYNTHETIC=1`.
If you run it, do not commit the result.

## 📊 The rankings themselves

They are not reproduced in this file. A table pasted into a README cannot be
regenerated, so it goes stale without going wrong-looking — which is precisely how
this README previously came to advertise a perfect score for the reference
implementation that no measurement ever supported.

Read [`results.csv`](results.csv), or regenerate it:

```bash
experiments/run_baselines.sh
```

Each row carries TP/FP/TN/FN, accuracy, precision, recall, F1, FPR/FNR, an exact
Clopper–Pearson recall interval, and latency mean and standard deviation with the
sample count.

## Three things to know before reading it

- **The reference implementation does not lead.** Layer 1 is a repository-edge
  secret and PII scanner; the corpus is cloud misconfigurations. It detects almost
  nothing here. That is a scope boundary reported as measured, not adjusted.
- **Latency is not comparable across layers.** The plan-level figure covers policy
  evaluation over an already-compiled plan and excludes the `terraform init` and
  `terraform plan` invocations that produce it. It is a lower bound.
- **The plan-level policy set was authored with knowledge of the corpus**, while
  the comparators ran default rulesets. The asymmetry favours the reference and is
  disclosed rather than corrected for.

Caveats that must accompany any citation of these numbers are recorded
machine-readably in `results/evaluation.json` under `caveats`.
