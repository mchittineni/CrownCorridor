# IaCSecBench Benchmark Evaluation Results (`results/`)

This directory contains empirical benchmark output data, summary metrics, comparative tables, and raw scanner output logs generated by the **IaCSecBench** evaluation framework.

## 📊 Directory Overview

```
results/
├── benchmark_results.json # Full benchmark scan evaluation output
├── corpus_report.json     # Analysis report across infrastructure corpus
├── evaluation.json        # Comparative scoring metrics (Precision, Recall, F1, Latency)
├── run_manifest.json      # Reproducible execution manifest and environment metadata
├── metrics.csv            # Summary metrics export for baseline tools
├── raw/                   # Raw outputs from static analysis scanners (Checkov, tfsec, etc.)
├── tables/                # Markdown and LaTeX formatted summary tables
└── charts/                # Exported visual performance and coverage charts
```

## 🔬 Reproducing Results

To generate fresh benchmark results and evaluation metrics:

```bash
# Execute baseline evaluations
bash experiments/run_baselines.sh

# Run synthetic leaderboard scoring (for development verification)
IACSECBENCH_ALLOW_SYNTHETIC=1 python3 evaluation/score.py
```
