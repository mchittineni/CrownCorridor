# `results/` — what is measured and what is not

This directory holds files of two kinds that a filename cannot distinguish. Read
this table before citing anything in it.

## Measured

Produced by `experiments/run_baselines.sh`, which executes real scanners and
records their unmodified output.

| File | Contents |
| :--- | :--- |
| `run_manifest.json` | **Authoritative record of a run.** Tool versions and resolved paths, platform, CPU count, git commit, repeat count, validation mode, per-case status and raw latency samples. Where any document disagrees with this file, this file is right. |
| `evaluation.json` | Confusion matrices at all three matching levels, exact Clopper–Pearson intervals, pairwise McNemar tests, and the caveats that must accompany the numbers. |
| `corpus_report.json` | Corpus admissibility per case, and the declared-versus-present counts for each external collection. |
| `raw/<tool>/<case>.json` | Unmodified scanner output, one file per tool per case. Everything else is derived from these. |
| `tables/*.tex` | Generated LaTeX tables. `paper/Makefile` refuses to typeset without them, so the manuscript cannot contain hand-written result tables. |
| `pre_opa_polarity_fix/` | Measured results from *before* a disclosed policy correction. See the README there. |

The measured leaderboard lives outside this directory, at
[`../leaderboard/results.csv`](../leaderboard/results.csv), and is generated by
`evaluation/analyze.py`.

## Synthetic — not measurements

**There are none. They were deleted.** Every file in this directory is a
measurement.

Files listed below used to sit here alongside the measured ones. No scanner was
executed for any of them: their metrics were corpus counts multiplied by hardcoded
per-tool rates, and some named tools this project has never run (`Sentinel`,
`Terratest`). They have been removed rather than annotated, because a warning
header does not survive the file being read by a script or a table being copied out
of it.

| Deleted file | Was produced by |
| :--- | :--- |
| `benchmark_results.json` | `pipeline/run_experiments.py` |
| `metrics.csv` | `experiments/generate_charts.py` |
| `charts/*.txt` | `experiments/generate_charts.py` |
| `../benchmark/reports/experiment_results.json` | `pipeline/run_experiments.py` |
| `../leaderboard/results.synthetic.csv` | `evaluation/score.py` |

The producing stages still exist and still work, but they refuse to run without an
explicit opt-in:

```bash
IACSECBENCH_ALLOW_SYNTHETIC=1 python pipeline/run_experiments.py
```

Anything they write is a projection of hardcoded rates, not a measurement. If you
run one, do not commit the output back here.

## Reproducing the measured results

```bash
experiments/run_baselines.sh              # 3 latency repeats
REPEATS=10 experiments/run_baselines.sh   # more latency samples
```

Measure latency on an otherwise idle machine. It is the one metric that reflects
the host rather than the tool: background load inflates the mean and can multiply
the standard deviation several-fold, and no number of repeats corrects for it.

## Why this file exists

A fabricated `benchmark_results.json` and a measured `evaluation.json` were
indistinguishable by name, location, and format. The failure mode is not that
someone disbelieves a caveat — it is that a plausible-looking file gets read by a
later stage, or pasted into a document, with no caveat in sight.

The fabricated files are now gone, which is a stronger guarantee than a warning
header. This index remains so that the distinction is documented, and so that
anyone who regenerates one of them knows not to leave it here. Deleted content is
recoverable from git history if it is ever wanted.
