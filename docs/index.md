## Architecture Overview

```
Browser
  └── app/index.html            Dashboard entry point
        ├── app/styles.css      Glassmorphism dark-theme design system
        └── app/portal.js       All portal logic:
              ├── SRO Ticker    Live registration feed (simulated; SRO API scaffold in pipeline/)
              ├── Map           Leaflet base + MapLibre GL + PMTiles cadastral overlay
              ├── Listings      Verified property cards with inquiry forms
              ├── Calculators   Stamp duty (AP 7.5%, TS 6.0%) and guidance-value estimator
              └── API Console   JSON query sandbox and webhook configuration

GitHub Actions
  ├── ci.yml              PR gate: data validator + 23 pytest cases
  ├── deploy-pages.yml    Builds _site/ (app/ + data/) → GitHub Pages
  ├── update-data.yml     Weekly SRO data refresh → reviewed PR
  ├── release.yml         Versioned release with downloadable data archives
  └── docs.yml            JSDoc build-check on portal.js changes

Data (static, committed)
  ├── data/andhra_pradesh/   28 districts · 684 mandals · 15,197 villages (LGD)
  └── data/telangana/        33 districts · 616 mandals · 9,287 villages (LGD)

Pipeline (server-side)
  ├── pipeline/validate_data.py    Data integrity checks (6 sections, both states)
  ├── pipeline/fetch_sro.py        SRO fetcher scaffold (exit-75 outage contract)
  └── pipeline/tests/              pytest suite (23 cases)
```
